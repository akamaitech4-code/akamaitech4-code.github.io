Welcome to Unified Origin home page

The purpose of this project is to provide all the necessary features for end-to-end testing, gathered in one place. Below you can find a list of supported "features", with description on how to use them.

General description

General description of provided features.

Mirroring

What you send is what you get.

All HTTP versions

By using subdomains you can connect with different HTTP versions.

GraphQL

Support for GraphQL queries.

JWT/JWKS

Support for JSON Web Tokens and JSON Web Key Sets.

Basic login form

Basic x-www-form-urlencoded POST request.

Images and video

Images and videos for Image Manager.

Cache control

Return current system timestamp with specified `Cache-Control` header directives to test caching mechanisms.

Custom protocol

Example page with HTML img tag and a tag with references containing custom schema in URL.

Desired response size

You can get random data as a response with desired size.

Edge Side Includes

Example pages containing ESI elements.

Web Socket

You can test WebSocket communication.
